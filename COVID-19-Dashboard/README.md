# COVID-19 Global Data Analysis Dashboard

## 📌 Project Overview

This project analyzes global COVID-19 data to identify trends and patterns in confirmed cases, deaths, recoveries, and active cases across different countries and over time.

The project was developed as part of my data analytics learning journey, with a focus on data cleaning, transformation, analysis, and interactive dashboard development.

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Excel

## 📊 Key KPIs

* Total Confirmed Cases
* Total Deaths
* Total Recovered
* Death Rate
* Recovery Rate
* Global Confirmed Cases
* Deaths Rate Trend
* Recovery VS Death
* Countries by Confirmed Cases

## 🔍 Analysis Performed

The dataset was cleaned and transformed before being analyzed in Power BI.

The dashboard uses interactive visualizations and filters to explore COVID-19 trends across countries and dates. The analysis focuses on understanding the distribution and progression of cases, deaths, and recoveries.

## 💡 Key Insights

* COVID-19 cases varied significantly across countries.
* Confirmed cases and deaths followed different trends over time.
* Interactive filters made it easier to compare countries and periods.
* Data cleaning and transformation played an important role in producing accurate dashboard results.
